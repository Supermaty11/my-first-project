# メモの置き場

## いままで

- 会話の計画: Cursor 内部の `.cursor/plans/`（エージェント用。人が探す場所ではない）
- ゲーム画面: `kings-cup.html`（製品コード。仕様書ではない）
- ユーザールール: Cursor 設定の「合意なしでは作業しない」

仕様を HTML に書かない。Cursor が検索・参照しやすい Markdown に書く。

## これから

プロジェクト直下:

```
dev/cursor/YYYY-MM-DD/
  README.md
  spec.md      # その日時点の仕様
  必要なら追加の md
```

- 日付が変わったら新しいフォルダを作る。古い日付は消さない。
- 最新仕様を探すときは、いちばん新しい日付の `spec.md`。
- コード（HTML/CSS/JS）と仕様メモは混ぜない。
- git: 「実装して」のあとに内容確認 → OKならコミット。push は別指示。まだリポジトリ未作成。
